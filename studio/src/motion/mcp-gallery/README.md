# MCP Showcase Media

Showcase covers and preview videos on `/mcp-setup` load directly from OpenMotion's
official template catalog CDN (`library/templates/catalog`), Skill catalog (`skillCatalog.ts`),
and Brand Kit catalog (`/motion-api/brand-kits/catalog`).

- `faceless_explainer.webp`: mid-video poster frame for the `higgsfield-faceless-video` Skill
  (whose upstream thumbnail captures the opening parchment frame before the watercolor scene appears).
- `studio-editing.mp4` and `studio-editing.jpg`: a muted editor-only excerpt and a poster
  frame from the repository's [OpenMotion Studio tour](../../../../docs/readme/studio-tour.zh-CN.mp4).
